## 2024-06-25 - Layout Thrashing with Variable Font Animations
**Learning:** Animating variable font properties (like `font-variation-settings: "wdth"`) and `font-stretch` frequently triggers layout invalidation. If DOM metrics like `getBoundingClientRect()` are polled inside a rapid event listener (like `pointermove`) on the same element or layout boundary, it forces the browser to perform synchronous layout recalculation on every mouse movement, significantly dropping frame rates (layout thrashing).
**Action:** Always cache bounding box metrics (`getBoundingClientRect()`, `offsetWidth`, etc.) during an interaction's start phase (e.g., `pointerenter` or `mousedown`) or update them on `resize`, rather than querying them continuously during the interaction event handler when animating CSS properties.
